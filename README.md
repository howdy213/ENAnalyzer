# ENAnalyzer

**希沃白板课件自动打包与管理工具**

ENAnalyzer 是一款面向教师/同学的 Windows 桌面工具，用于自动扫描、校验和打包希沃白板（EasiNote 5）的课件文件，将其转换为可保存、可迁移的 `.enbx` 格式。支持手动打包、后台队列、自动转存、跳过管理、失败统计、打包记录去重等功能，帮助高效备份和整理课件资源。

## ✨ 主要功能

### 📦 课件打包为 ENBX 格式

- 扫描希沃白板本地数据目录，自动识别所有账户下的课件。
- 支持手动勾选批量打包，或开启自动转存。
- 生成完整的 `.enbx` 打包文件，包含课件资源及 `[Content_Types].xml`。
- 可选将课件配置 JSON、甚至未被引用的文件一并备份到包内 `dist/` 目录，便于排错与修复。

### 🧵 后台打包队列

- 打包任务在独立后台线程中**串行执行**，不阻塞界面操作。
- “打包队列”页实时显示每个任务的状态、来源（手动/自动）、进度、说明和输出路径。
- 自动忽略已在等待/打包中的同一课件，避免重复入队。
- 支持清空已完成的任务；底部进度条同步显示当前任务进度。

### 🔍 文件完整性校验

1. **文件存在性**：检查课件文件是否实际存在。
2. **下载状态**：通过 `FilePartialState` 字段判断文件是否完全下载。
3. **文件大小匹配**：对比期望大小与实际大小。
4. **MD5 哈希校验**（可选）：开启后进一步确保文件内容未被篡改或损坏。

### ⏱ 自动转存

- 启用后定时扫描监控目录（约每 8 秒），发现课件被修改且未打包（或已更新）时自动入队打包。
- 扫描在后台线程执行，打包交由后台队列处理，界面保持流畅。
- **防重复机制**：结合打包历史与最近打包状态判断，同一版本不会重复触发。
- **后台静默运行**，支持最小化到系统托盘。

### ⏭️ 跳过管理

- **手动跳过**：可将不需要备份的课件标记为“跳过”，自动转存将忽略它们。
- **智能自动跳过**：当某课件连续 **4 次** 自动校验失败（文件不完整），系统会自动将其永久跳过，并记录原因。
- 支持“标记已打包”，用于导入已有备份后的状态同步。

### 🧹 打包记录管理

- 完整记录每次打包（成功、失败、跳过、撤销）的时间、路径和原因。
- **去重**：保留每个课件的最新打包记录。
- **去除过期记录**：自动识别源课件已被删除的记录，批量清理。
- 支持单条/多条删除，双击记录可直接打开对应的打包文件。

### 📊 首页概览

- 显示最近修改的 6 个课件卡片，包含账户、作者、修改时间、大小和打包状态。
- 双击卡片可直接打开该课件最近一次成功打包的 `.enbx` 文件。

### 📁 灵活的输出路径

- 支持按账户（手机号）分文件夹存放，或统一输出到根目录。
- 可为每个账户单独指定自定义输出路径。

### ↩ 撤销打包

- 自动打包成功后弹出浮窗通知，可在 7 秒内**撤销**该次打包：删除已生成文件并标记为跳过。
- 通知可关闭，也可设置距屏幕底部的高度，并支持“预览通知”。

### 💾 备份与通知选项

- **保存课件配置 JSON 到 dist/**：将原始 JSON 一并打入包内。
- **保存未使用的文件到 dist/**：额外备份课件目录中未被 JSON 引用的文件（自动包含配置 JSON）。
- **显示浮窗通知**：控制自动打包完成后的撤销提示是否出现。

### 🧹 Dependencies 目录清理

- 监视希沃白板缓存目录（`%APPDATA%\Seewo\EasiNote5\Dependencies`）。
- 可将指定子目录加入监视列表，程序定时自动删除，释放磁盘空间。
- 支持添加/取消监视、手动删除目录，并显示目录用途说明。

### 🚫 自动关闭 EasiNote 窗口

- 可配置自动关闭 EasiNote 进程产生的窗口。
- 支持按窗口**标题**匹配，内置常用标题，也可手动添加自定义标题。
- 定时扫描并关闭匹配的子窗口，保持教学环境整洁。

### 🛡 防多开机制

- 程序启动时自动检测是否已有实例运行，避免多开导致的资源冲突。
- 已有实例时，普通模式弹出友好提示；`-silent` 静默模式则直接退出，不干扰后台任务。

### 🛠 更多

- 系统托盘图标，关闭窗口后继续后台运行。
- 搜索功能：按课件名称快速过滤。
- 列表列排序：按名称、作者、修改时间、大小排序。
- 多选操作：全选、取消全选、标记已打包、标记为跳过、还原状态、删除课件源文件。
- **命令行参数**：支持 `-silent`（启动时不显示主窗口，直接驻留系统托盘）与 `-toast "消息"`（仅弹出浮窗通知后退出）。
- **开机自启服务**：内置 `tools\AutoStartService.exe`，可在“转存设置”中一键安装/卸载，服务以 `-silent` 方式启动程序。
- 适配高 DPI 显示，设置页支持滚动查看。

## 🚀 快速开始

### 环境要求

- Windows 10 / 11（需存在希沃白板本地数据目录）。
- 直接使用打包好的 `ENAnalyzer.exe` 时无需安装 Python。
- 从源码运行需 Python 3.8+ 和 wxPython（`pip install -r requirements.txt`，要求 `wxPython>=4.0`）。

### 使用步骤

1. **下载并运行**：双击 `ENAnalyzer.exe`；或从源码执行 `pythonw ENAnalyzer.pyw`。
2. **首次启动**：程序会自动定位默认的希沃数据目录（`%APPDATA%\Seewo\EasiNote5\Data`）。
3. **浏览课件**：在“课件管理”标签页即可看到所有账户下的课件。
4. **手动打包**：勾选需要备份的课件，点击“打包选中的课件”，选择保存目录即可；任务会进入“打包队列”后台执行。
5. **开启自动转存**：进入“转存设置”，勾选“启用自动转存”，保存设置后程序将自动监控并打包新修改的课件。

#### 静默启动（开机自启）

若希望程序在系统启动时自动运行并隐藏窗口，可在“转存设置”底部安装开机自启服务：

- 服务通过 `tools\AutoStartService.exe`（配置见 `tools\asconfig.ini`）以 `-silent` 启动程序。
- 程序仅驻留系统托盘，不弹出主界面。
- 配合自动转存功能，可无人值守地持续备份课件。

#### 浮窗通知（`-toast`）

供其他程序调用的轻量通知模式：

```cmd
ENAnalyzer.exe -toast "已备份到: 英语\课件_20251113_101530.enbx"
```

- 只显示一个底部浮窗，不创建主窗口、不驻留托盘，显示完自动退出。
- 浮窗不抢焦点，也不占用单实例互斥，可与正在运行的 ENAnalyzer 同时存在。
- 无撤销按钮，点击 ✕ 或等待 7 秒后关闭；浮窗距底部高度沿用设置中的“通知距离底部高度”。

#### 从源码构建

```powershell
pip install -r requirements.txt pyinstaller
pyinstaller ENAnalyzer.spec
```

构建产物位于 `dist\ENAnalyzer\`。

### 配置说明

所有设置保存在程序目录下的 `config/settings.json`，也可通过“转存设置”界面修改：

- `auto_pack`：是否启用自动转存。
- `monitor_dir` / `output_root`：监控目录与输出根目录。
- `by_account` / `account_paths`：是否按账户分文件夹，以及各账户的自定义输出路径。
- `skip_cids` / `fail_counts`：已跳过的课件与连续校验失败计数。
- `enable_hash_check`：是否启用 MD5 哈希校验。
- `show_toast` / `toast_bottom_margin`：是否显示浮窗通知及其距底部高度。
- `backup_config` / `backup_unused`：是否备份配置 JSON / 未使用文件到 `dist/`。

**功能设置**标签页使用独立配置文件 `config/function_settings.json`，保存 Dependencies 监视列表、自动关闭窗口标题及启用状态等，可通过界面管理。

## 🧩 打包文件说明

生成的 `.enbx` 文件本质是一个 ZIP 压缩包，包含：

- 课件的所有资源文件（图片、音频、字体等）
- 符合 Open XML 规范的 `[Content_Types].xml`（较希沃正常内容略有多余，但不影响使用）
- 可选的 `dist/` 目录：课件配置 JSON，以及（若开启）未被引用的其他文件

生成的 `.enbx` 可直接使用希沃白板导入，或作为备份存档。
